# Daily Planner

Description: Interactive and dynamic daily planner for 3 weeks. A color-coded progress bar shows the completion rate of written tasks for each day. Each new day the planner is opened, the start date is automatically adjusted to the open date. Each task is specific to the date, so all tasks shift accordingly with each respective date even when calendar changes.
